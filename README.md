# project-surprise

Project SURPRISE is an interactive cinematic storytelling platform built using Go, Chi Router, Next.js and MySQL.

The goal of the project is to create an immersive story-driven experience where technology fades into the background and emotions take the center stage.

## Tech Stack

- Go
- Chi Router
- Next.js
- TypeScript
- Tailwind CSS
- MySQL
- Docker
- Framer Motion
- GSAP
